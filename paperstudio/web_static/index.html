关于保真度
Markdown 优先保持可编辑的文档结构；PDF 重排无法保证所有页面与原文逐像素一致，复杂公式、跨页表格应对照原件复核。
关于隐私
网页服务器默认只监听 127.0.0.1。使用 Ollama 可在本机处理；使用 DeepSeek / OpenAI / DeepL / 远程 LibreTranslate 会接收待翻译的文本。
